# perfect-world-cons
Генератор решений для испытания «Созвездия» в подземелье «Гробница Шепотов» онлайн-игры Perfect World. Интерактивная версия расположена на [отдельной странице](https://classes123.github.io/perfect-world-cons/). 

> [!IMPORTANT]
> Все сообщения об ошибках принимаются исключительно в [Issues](https://github.com/Classes123/perfect-world-cons/issues/new/choose). Если есть подходящая категория, пожалуйста, выбирайте её.
